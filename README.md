# ACNextGen_Enhanced_Physics_plugin

ACNextGen Native は、Assetto Corsa の車両状態を入力としてのACNextGenを
(過去のリポジトリを参照 ACNextGen_Enhanced_Physics）
51のluaからC++モデルに変更し
実行する開発プロジェクトです。モデルの状態はゲーム内の Observer から確認できます。

準備中の技術プレビューはオフライン観測を対象とし、追加の力・トルクは既定で無効です。車両データの変更は不要です。配布物と導入手順は、検証を終えた版のリリースに掲載します。
