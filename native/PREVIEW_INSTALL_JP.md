# ACNextGen Native 技術プレビュー

Assetto Corsaの車両状態を入力に、51のC++モデルを実行し、その状態をゲーム内のObserverで確認できる開発プレビューです。既定は観測モードで、追加の力・トルク出力は無効です。

## 導入と起動

1. Assetto Corsaの走行を終了します。以前のACNextGen NativeをGeneric Modsで有効にしている場合は、先に無効にします。手動導入した場合は、旧版の設定を退避してから導入してください。
2. ファイル名に `-CM-` を含む配布ZIPをContent Managerへドラッグ＆ドロップし、Generic Modsで有効にします。通常は配布ZIPを一つだけ使用します。
3. オフラインセッションを開始し、右側のアプリ一覧からACNextGen Observerを開きます。Stopで演算を停止し、Resumeで観測を再開します。
4. 削除や旧版への復帰は、走行を終了してからGeneric Modsでこの版を無効にします。その後、必要に応じて旧版を有効にします。

CMの実画面での導入は未検証です。ZIPの配置構造と内容は検証済みです。

## 対応範囲

このプレビューはオフライン専用です。Observerと共通Workerはオンラインセッションでは起動条件を満たしません。検証したCSP 0.3.1（patch4302）では、コースに `ALLOW_APPS=1` がある場合も共通Workerの物理許可が得られませんでした。

51モデル個別の実ゲームでの挙動寄与は検証中です。Observerに入力や候補値が表示されても、追加の力やトルクが車両に適用されたことを示すものではありません。

## 動作報告

配布ZIPのファイル名、CSPの版、車両とコース、再現手順、Stop／Resumeでの変化、Observerの表示を添えてください。性能の報告には、同じ条件で計測したFPSまたはフレーム時間があると比較できます。ログを添える場合は、再現に必要な範囲からユーザー名や個人フォルダーのパスを取り除いてください。
